# PricePilot AI Backend

This directory contains the FastAPI backend for the PricePilot AI project.

It follows Clean Architecture principles to ensure scalability, maintainability, and testability.

## Quick Start

1. Create a virtual environment: `python -m venv venv`
2. Activate the virtual environment.
3. Install dependencies: `pip install -r requirements.txt`
4. Set up environment variables in `.env`.
5. Run the application: `uvicorn main:app --reload`
